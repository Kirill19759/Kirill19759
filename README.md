## Чем помогаю

Нужен не «внедрить искусственный интеллект», а результат, которым можно пользоваться через 2–4 недели.

- разобрать таблицу и ответить на вопрос бизнеса;
- оценить, какие заявки, клиенты или события ближе к нужному результату;
- собрать небольшой сервис: загрузка файла, расчёт, выгрузка, API;
- автоматизировать повторяющуюся работу с данными и отчётами.

Формат: письмо с целью и составом данных → оценка срока и стоимости → фиксированный пилот → акт и чек.
